# Theophysics Sync Manager (Obsidian Plugin)

Provides a sync dashboard, manual triggers, and conflict resolution UI for the Theophysics sync backend.

## Installation
1. Copy `obsidian-plugin` into your `.obsidian/plugins/` directory.
2. Run `npm install` and `npm run build`.
3. Enable **Theophysics Sync Manager** in Obsidian.

## Usage
- Command palette → **Open sync dashboard**.
- Command palette → **Trigger sync** to run a manual sync.
- Resolve conflicts from the dashboard.

## Settings
- **API Base URL**: Address of the Python backend.
- **Auto-sync**: Trigger sync on plugin startup.
